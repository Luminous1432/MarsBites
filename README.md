# Cosmic Restaurant Website 🌌

**Cosmic Restaurant** is a futuristic, interactive front-end website built using **HTML, CSS & JavaScript**. This project was created by **Shriraksha Gourayya** for the **WebWave Frontend Making Competition**.

---

## Features ✨

- Home, About, Menu, and Contact pages  
- Futuristic menu with pop-up dish details  
- Order page with customer form  
- Demo order tracking animation  
- Floating sparkles and interactive hover effects  
- Responsive and visually engaging interface  

---

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla)
- Animations: GSAP, CSS keyframes
